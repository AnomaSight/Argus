## Summary
Scripts that put both datasets into `data/` in a known layout.

## Why this matters
Everything downstream reads from `data/`. A script makes setup on a new machine (e.g. Colab) repeatable.

## What to do
1. `scripts/download_mvtec_ad.sh`: MVTec requires accepting its licence on the website, so the script takes a path or URL to the downloaded archive, verifies it, and extracts to `data/mvtec_ad/`.
2. `scripts/download_isp_ad.sh`: fetch the public unsupervised split from Zenodo (record 14911043) only, not the full 559k-sample dataset. Check archive sizes first and download only what is needed.
3. Verify integrity (checksums if published, otherwise file counts) and print per-category / per-modality counts.
4. Make both scripts idempotent: rerunning skips files that already exist.

## Deliverables
- Two download scripts
- Counts recorded in `docs/experiment_protocol.md`
