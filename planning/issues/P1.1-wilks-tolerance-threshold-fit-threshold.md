## Summary
Implement Deng's distribution-free cut-off: pick a rank in the sorted calibration scores so that FPR ≤ alpha with confidence 1 − delta.

## Why this matters
This is how the project sets every cut-off. Arvind needs it for ISP-AD and the review zone (handoff H2).

## What to do
1. Sort calibration scores. Choose the smallest rank r such that P(Z ≥ m − r + 1) ≥ 1 − δ, where Z ~ Binomial(m, α). Set tau = r-th smallest score.
2. Use `scipy.stats.binom.sf` for the tail probability.
3. Return the C4 `Threshold` object; raise a clear error when even the maximum (r = m) can't reach 1 − δ.
4. Save/load `threshold.json`.
