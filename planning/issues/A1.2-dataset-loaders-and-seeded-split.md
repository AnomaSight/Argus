## Summary
Load both datasets and write the C1 split manifests for every category/modality and seed.

## Why this matters
The split manifest is the single source of truth for which image does what. Getting it right once prevents data leakage everywhere.

## What to do
1. `data/mvtec_ad.py` and `data/isp_ad.py`: list images with label, defect type and mask path.
2. `data/splits.py`: given a dataset config and seed, assign roles exactly as configured in 0.4 and write the C1 CSV.
3. Use `numpy.random.default_rng(seed)`; sort file lists before shuffling so results don't depend on filesystem order.
4. `data/transforms.py`: preprocessing presets — `patchcore` (resize 256, center-crop 224, ImageNet normalisation) and `deng` (resize 256×256, no crop).
5. CLI: `argus splits --dataset mvtec_ad --category hazelnut --seeds 1 2 3`.

## Deliverables
- Loaders
- Split generator + CLI
- Manifests for all chosen categories/modalities and seeds
