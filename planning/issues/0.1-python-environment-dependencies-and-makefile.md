## Summary
Set up one Python environment that both of you install the same way, and the Makefile targets everyone uses.

## Why this matters
Every other Python task needs a working, identical environment. Pinning versions now prevents "works on my laptop" bugs later.

## What to do
1. Fill `pyproject.toml`: project name `argus`, `src/` layout, Python >= 3.10.
2. Runtime deps: torch, torchvision, numpy, scipy, pandas, pyarrow, scikit-learn, pyyaml, opencv-python-headless, pillow, tqdm.
3. Optional groups: `[api]` fastapi, uvicorn, python-multipart; `[dev]` pytest, ruff.
4. Makefile targets: `install` (pip install -e '.[api,dev]'), `test` (pytest), `lint` (ruff check), `format`.
5. Fill `.env.example` with `ARGUS_DATA_DIR=data`, `ARGUS_ARTIFACTS_DIR=artifacts`, `ARGUS_DEVICE=cuda`.
6. Add a 10-line Colab note in `README.md`: clone, `make install`, mount Drive for `data/` and `artifacts/`.
7. Add one trivial test (`import argus`) so `make test` has something to run.
