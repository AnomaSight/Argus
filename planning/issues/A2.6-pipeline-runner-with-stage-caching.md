# [A2.6] Pipeline runner with stage caching

## Summary
One command that runs features → coreset → scores for a config and writes C2 score files, skipping stages that are already done.

## Why this matters
Makes all experiments reproducible from configs and cheap to rerun.

## What to do
1. `pipeline/stages.py`: stages `features`, `banks`, `scores`; each has inputs, outputs and a config-hash key.
2. `pipeline/runner.py`: run a stage only if its output for that hash is missing; `--force` to rerun.
3. Write `scores.parquet`, heatmaps and `run.json` per C2; measure ms/image (GPU-synchronised, warm-up excluded) and bank MB.
4. `utils/config.py`: load YAML with `configs/default.yaml` + dataset + experiment overrides; compute the hash.
5. CLI: `argus run configs/experiments/memory_sweep.yaml --dataset mvtec_ad --category hazelnut --seeds 1 2 3`.

## Deliverables
- Runner + CLI
- `configs/default.yaml`
- `configs/experiments/memory_sweep.yaml`

## Done when
- [ ] Re-running a finished config completes in seconds
- [ ] Changing only the seed reuses cached features
- [ ] Tests for this module pass in CI / `make test`
