## Summary
Implement `/models` and `/inspect` per C5, backed by a fake detector that follows C3.

## Why this matters
Lets the frontend be built end to end now. Swapping in the real detector later is a one-line change (P3.2).

## What to do
1. `services/model_registry.py`: interface `get(model_id) -> Detector`; a `StubDetector` returns a deterministic score and a blob-shaped heatmap.
2. `routers/models.py` and `routers/inspect.py` per C5; `schemas.py` with Pydantic models.
3. `services/inference.py`: decode upload, call detector, compare with tau, render heatmap PNG (colour map + overlay).
4. Validate uploads (type, size limit).
