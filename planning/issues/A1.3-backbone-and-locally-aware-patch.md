## Summary
Turn an image into PatchCore's patch features using WideResNet-50 layers 2 and 3.

## Why this matters
This is PatchCore's representation. Every score in the project comes from these features, so they must match the paper.

## What to do
1. `features/backbone.py`: torchvision `wide_resnet50_2` with ImageNet weights, eval mode, frozen; forward hooks return layer2 and layer3 outputs.
2. `features/patch_features.py`: 3×3 local average aggregation (stride 1, padding 1) on each layer; bilinearly upsample layer3 to layer2's grid; project each layer to a fixed dimension with adaptive average pooling over channels (official repo default: 1024), then concatenate and pool to the target dimension.
3. Output shape: (H·W, D), e.g. 28×28 = 784 patches at 224 input, 32×32 = 1024 at 256 input (Deng's setup).
4. Run under `torch.inference_mode()`, batch images, optionally autocast to half precision on GPU.
