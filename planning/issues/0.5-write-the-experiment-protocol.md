## Summary
Write down every rule of the experiment before any results exist.

## Why this matters
Fixing the protocol up front is what makes the results trustworthy: nobody can (even accidentally) tune choices after seeing test numbers.

## What to do
1. Seeds, datasets, categories and split sizes (from 0.4).
2. Memory settings: 100%, 10%, 1%, ASO; what is held fixed (backbone, layers, input size, preprocessing).
3. Calibration: Wilks one-sided tolerance threshold, confidence 95%, targets 10% / 5% / 2% (2% only where m ≥ 149), strict `score > tau`.
4. Metrics reported: FPR and recall at tau (with Wilson CIs), image AUROC, pixel AUROC, PRO, bank size, ms/image, setup time.
5. Fair-test rules: one threshold per setting per seed; test set read only after thresholds are saved; negative results reported.
6. How results are aggregated over seeds (mean and min–max).
