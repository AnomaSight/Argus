## Summary
Run PatchCore-10% with the full MVTec training set on the chosen categories and compare AUROC with published values.

## Why this matters
If the baseline doesn't match the papers, every later result is suspect. This is the implementation's sanity check.

## What to do
1. Config with no hold-out (all training goods as support), `patchcore` preset, 10% coreset.
2. Compute image AUROC (P1.4) and pixel AUROC / PRO (P2.1, if merged) on the original test set.
3. Compare with the ASO paper's Table 1 baseline (WRN-101: hazelnut 100.0, screw 98.7 image AUROC) and PatchCore's per-category supplementary table; WRN-50 may be slightly lower.

## Deliverables
- Short comparison table in `docs/results.md` (baseline section)
