## Summary
Score each image by its most unusual patch and produce a heatmap.

## Why this matters
Produces every score the analysis uses.

## What to do
1. Patch score = distance to nearest bank patch (`knn`, k = 1).
2. Image score = max patch score. Implement PatchCore Eq. 7 reweighting (b nearest neighbours) as a config option; check which the official repo uses by default and match it for the baseline. Deng's ISP-AD setup uses plain max k = 1.
3. `scoring/heatmap.py`: reshape patch scores to the grid, bilinear upsample to input size, Gaussian blur σ = 4.
