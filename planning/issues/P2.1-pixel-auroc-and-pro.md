## Summary
Localisation metrics from heatmaps and defect masks.

## Why this matters
Needed to compare with the PatchCore and ASO papers and to report heatmap quality per memory setting.

## What to do
1. Pixel AUROC over all test pixels (heatmaps and masks at the same resolution).
2. PRO: for each connected defect region, overlap with the thresholded heatmap; average over regions; integrate PRO vs pixel FPR up to 0.3 and normalise by 0.3.
3. Stream over images so memory stays bounded.
