## Summary
Read a folder of C2 score files, calibrate on `calib`, evaluate on `eval_normal` + `test`, and output the results table.

## Why this matters
One tool builds every results table in the project, for both datasets and both people.

## What to do
1. For each (setting, seed): load scores → `fit_threshold` on `calib` → save `threshold.json` → only then read `eval_normal` and `test` rows (test-set lock).
2. Columns: setting, FPR (CI), recall (CI), image AUROC, pixel AUROC, PRO, bank MB, ms/image, setup s; aggregate seeds as mean and min–max.
3. Targets from config (10% / 5% / 2%); skip and warn where m is too small.
4. Output CSV + Markdown to `artifacts/results/{dataset}/{category}/`.
5. CLI: `argus report --dataset mvtec_ad --category hazelnut --alpha 0.05`.
