## Summary
Create runnable empty shells for the React frontend and the FastAPI backend.

## Why this matters
Gets tooling problems (Node versions, CORS, ports) out of the way before any real feature work.

## What to do
1. Frontend: Vite + React + TypeScript in `frontend/`. Fill `package.json`, `vite.config.ts` (dev proxy `/api` → `http://localhost:8000`), `tsconfig.json`, `index.html`, `src/main.tsx`, `src/App.tsx`.
2. Backend: `backend/app/main.py` creates the FastAPI app, enables CORS for the Vite dev port, includes `routers/health.py` with `GET /health` → `{"status": "ok"}`.
3. `backend/app/config.py`: settings read from env (artifacts dir, allowed origins).
4. Add `make api` (uvicorn with reload) and `make web` (npm run dev) to the Makefile.

## Deliverables
- Runnable frontend shell
- Runnable backend with `/health`

## Done when
- [ ] `make api` serves `/health`
- [ ] `make web` shows the app and it can call `/api/health` through the proxy
- [ ] Tests for this module pass in CI / `make test`
