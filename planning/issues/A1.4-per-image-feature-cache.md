## Summary
Compute each image's patch features once and reuse them for every seed and memory setting.

## Why this matters
The CNN pass is the most expensive step. Because splits are just lists of image ids, caching per image means changing seeds or memory settings never reruns the CNN.

## What to do
1. `features/cache.py`: key = (dataset, image_id, preprocessing preset, backbone config hash).
2. Store float16 arrays under `artifacts/features/{dataset}/{preset_hash}/{image_id}.npy` (or one memory-mapped file per category for speed).
3. API: `get_features(image_ids) -> np.ndarray` computes missing ones in batches and loads the rest.
4. Log cache hits/misses and total size.

## Deliverables
