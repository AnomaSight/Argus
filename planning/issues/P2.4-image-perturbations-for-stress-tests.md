## Summary
Deterministic image changes that mimic real factory drift.

## Why this matters
Used to test whether a cut-off calibrated on clean images still holds when conditions change.

## What to do
1. `stress/perturbations.py`: brightness, contrast, Gaussian blur, JPEG compression; 3–5 severity levels each, defined in `configs/experiments/stress.yaml`.
2. Pure functions `PIL.Image -> PIL.Image`; seeded where randomness is involved.
3. Notebook showing one image at every level for a visual check.
