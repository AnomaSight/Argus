## Summary
Pick each category's coreset size from the d(k) curve, as in ASO PatchCore.

## Why this matters
ASO is one of the four memory settings being compared.

## What to do
1. Normalise: k̃ = k / k₁₀%, d̃ = d(k) / d(k₁₀%).
2. k* = argmin over 1 ≤ k ≤ k₁₀% of sqrt(k̃² + d̃²).
3. Return k* and the fraction k*/N; save the curve for P4.2's figure.
